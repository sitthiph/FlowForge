# FlowForge

A local-first workflow orchestration engine built in Go.

## Development Status

Currently in development.
## Requirements

- Go 1.27.4
- Git

## Run

```bash
go run .
```

## Build (Windows)

```bash
go build -o flowforge.exe .
```

## Test

```bash
go test -v -count=1 ./...
```
